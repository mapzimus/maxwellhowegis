What I’ve been making lately

30 Day Map Challenge

A map a day through November, all New England. Twenty-four done so far, including every lighthouse in Massachusetts, 1911 railroads, a fantasy T map, 72 rotaries, 5.3 million buildings, and a 3D map of New England's cows.

Optimal Drives

It started with Optitrek, a road-trip optimizer side project. Now an OSRM server on my own machine solves the shortest drive to every McDonald’s, every Massachusetts town, and every pub in the UK. About 50 videos so far.
